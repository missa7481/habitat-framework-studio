How to read the atlas

What the maps show

The input map shows where the environmental features were available in 2024. The sector map compares two models on six held-out sectors in a separate broad-area reporting study.

What the ranking measures

The main benchmark asks how well each model predicts the mix of five mosquito categories among submitted reports. It compares 44 configurations on the same 20 held-out splits. Survey detection and habitat suitability have their own evaluation targets.

What a gain means

A 0.35% reduction in average log loss means the winning configuration assigned slightly more probability to the categories people reported than the forest using the same input sources. The ranking changes with the metric and the region held out.
